# Problem Statement: Interactive Terminal Calculator

## Objective
To develop a terminal-based, user-friendly interactive calculator in Python capable of executing fundamental mathematical operations continuously until terminated by the user.

## Scope of Work
1. **Arithmetic Operations:** Support standard binary operations including addition, subtraction, multiplication, and division.
2. **Control Flow:** Implement interactive loops allowing repeated calculations without restarting the script.
3. **Validation & Exception Handling:** 
   - Safeguard division operations against zero-denominator scenarios.
   - Gracefully process non-numeric inputs and unsupported operator selections.
4. **Command-Line Executability:** Ensure complete usability in pure CLI environments without graphical user interfaces (GUI).

## Course Concepts Applied
- **Module 3:** Python Operators (Arithmetic & Logical Operators)
- **Module 4:** Input and Output Operations (`input()`, `print()`)
- **Module 6:** Type Conversion (`int()`, `float()`)
- **Module 8:** Control Flow Statements (`while` loops, `if-elif-else` conditionals)
