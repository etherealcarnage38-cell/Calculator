# Console Calculator Project

A lightweight, terminal-based interactive calculator written in Python for basic arithmetic operations.

## Features
- Performs basic arithmetic: Addition, Subtraction, Multiplication, and Division.
- Interactive terminal menu with continuous loop execution.
- Includes division-by-zero protection and robust input error handling.

## Requirements
- Python 3.x installed on your system.
- No external third-party dependencies required.
